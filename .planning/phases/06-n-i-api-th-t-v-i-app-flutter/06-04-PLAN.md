**Đã xác minh trực tiếp mã backend (không suy đoán):** `JwtAuthFilter` bắt riêng `ExpiredJwtException` (set `TOKEN_EXPIRED`) khác với `JwtException`/`IllegalArgumentException` cho chữ ký sai/định dạng sai (set `TOKEN_INVALID`) — hai nhánh KHÁC NHAU. Trước bản sửa của 06-01 Task 2, cả hai đều bị `GlobalExceptionHandler.handleAuthentication` làm phẳng thành `UNAUTHENTICATED`; sau bản sửa, response 401 trả đúng `error.code` tương ứng. Do đó chuỗi JWT sai chữ ký (`invalid-signature-force-expired-path`) sẽ kích hoạt `TOKEN_INVALID`, KHÔNG PHẢI `TOKEN_EXPIRED` — `AuthInterceptor.onError` (theo `api/00-QUY-UOC-CHUNG.md` mục 8) chỉ refresh khi thấy `TOKEN_EXPIRED`. Vì vậy phương án DUY NHẤT đúng là ký một JWT THẬT với `exp` quá khứ, cùng thuật toán HS256 và cùng secret dev (`JWT_SECRET`) mà backend dùng — không dùng chuỗi chữ ký sai.

import 'package:dart_jsonwebtoken/dart_jsonwebtoken.dart';
import 'package:dio/dio.dart';
import 'package:finance_ai/core/config/app_config.dart';
import 'package:finance_ai/core/network/api_client.dart';
import 'package:finance_ai/core/network/token_storage.dart';
import 'package:flutter_test/flutter_test.dart';
import 'package:integration_test/integration_test.dart';

/// SC5 / D-13b: nhiều request cùng hết hạn thẻ chỉ gây MỘT lần gọi /auth/refresh,
/// phiên không bị thu hồi oan. Dùng TokenStorage.saveForTest (test-only, xem token_storage.dart)
/// để seed access token đã hết hạn mà không cần chờ 3600s thật.
///
/// Token hết hạn được KÝ THẬT bằng cùng JWT_SECRET backend dùng (đọc từ
/// --dart-define=JWT_SECRET=... khi chạy test, KHÔNG hardcode) — đã xác nhận qua đọc
/// GlobalExceptionHandler.java/JwtAuthFilter.java rằng chỉ ExpiredJwtException mới trả
/// đúng error.code=TOKEN_EXPIRED (kích hoạt AuthInterceptor.onError); chuỗi chữ ký sai
/// trả TOKEN_INVALID, KHÔNG kích hoạt refresh.
///
/// GIỚI HẠN: không đo trực tiếp số lần /auth/refresh được gọi từ phía app test — test này
/// chỉ xác nhận HÀNH VI BÊN NGOÀI đúng: cả 3 request song song đều cuối cùng thành công
/// (200), và phiên vẫn dùng được sau đó (không bị thu hồi oan). Đếm số lần /auth/refresh
/// thật qua log backend được thực hiện ở checkpoint Task 4 của 06-05-PLAN.md (D-14).

/// TIỀN ĐIỀU KIỆN: test tự kiểm chứng ngay trước bước gộp refresh rằng token hết hạn thật
/// sự trả error.code=TOKEN_EXPIRED (không phải TOKEN_INVALID/UNAUTHENTICATED) — nếu bản sửa
/// GlobalExceptionHandler ở 06-01 Task 2 bị bỏ sót, lỗi hiện RÕ ngay ở bước precheck này thay
/// vì fail mơ hồ ở assertion cuối cùng.
void main() {
  IntegrationTestWidgetsFlutterBinding.ensureInitialized();

  testWidgets('SC5: nhiều request cùng hết hạn thẻ chỉ gộp 1 lần refresh', (tester) async {
    final tokenStorage = TokenStorage();
    final apiClient = ApiClient(tokenStorage: tokenStorage, onSessionExpired: () {});

    // 1. Đăng nhập thật để có refresh_token hợp lệ và userId thật (sub của JWT giả phải khớp).
    final loginResponse = await apiClient.post('/auth/login', body: {
      'email': 'seed.user@datn.local',
      'password': 'SeedPass123!',
    });
    final validRefreshToken = loginResponse['refresh_token'] as String;
    final userId = (loginResponse['user'] as Map<String, dynamic>)['id'] as String;

    // 2. Ký JWT access token THẬT với exp quá khứ, cùng secret dev backend dùng (jwt.secret
    // application.yml -> ${JWT_SECRET}, base64-decode trước khi ký vì JwtService dùng
    // Keys.hmacShaKeyFor(Base64.getDecoder().decode(secret))).
    final secretBase64 = const String.fromEnvironment('JWT_SECRET');
    expect(secretBase64, isNotEmpty,
        reason: 'Chạy test với --dart-define=JWT_SECRET=<giá trị JWT_SECRET của backend dev>');
    final key = SecretKey(secretBase64, isBase64Encoded: true);
    final jwt = JWT({
      'sub': userId,
      'plan': 'free',
    });
    final expiredAccessToken = jwt.sign(
      key,
      algorithm: JWTAlgorithm.HS256,
      expiresIn: const Duration(seconds: -10), // exp quá khứ 10 giây.
      noIssueAt: true,
    );

    // 3. Ghi đè access token bằng thẻ hết hạn giả lập, giữ nguyên refresh_token THẬT.
    await tokenStorage.saveForTest(
      AuthTokens(accessToken: expiredAccessToken, refreshToken: validRefreshToken),
    );

    // 3b. XÁC NHẬN TIỀN ĐIỀU KIỆN trước khi chạy phần còn lại: JWT hết hạn vừa ký PHẢI khiến
    // backend trả error.code = TOKEN_EXPIRED (không phải TOKEN_INVALID/UNAUTHENTICATED). Đây là
    // tiền đề bắt buộc để AuthInterceptor.onError kích hoạt refresh ở bước 4 — nếu 06-01 Task 2
    // (đọc lại JwtAuthFilter.ATTR_TOKEN_ERROR trong GlobalExceptionHandler) bị bỏ sót hoặc lỗi,
    // lỗi phải hiện RÕ NGAY ở đây, không lẫn vào assertion mơ hồ của bước 5/6. Dùng Dio TRẦN
    // (không qua ApiClient/AuthInterceptor) để đọc thẳng response 401 gốc, tránh bị interceptor
    // tự động refresh che mất giá trị error.code thật.
    final rawDio = Dio(BaseOptions(
      baseUrl: AppConfig.baseUrl,
      validateStatus: (_) => true,
    ));
    final precheckResponse = await rawDio.get(
      '/auth/me',
      options: Options(headers: {'Authorization': 'Bearer $expiredAccessToken'}),
    );
    expect(precheckResponse.statusCode, 401,
        reason: 'Token vừa ký phải hết hạn thật (exp quá khứ 10 giây)');
    final precheckCode = precheckResponse.data['error']['code'];
    expect(precheckCode, 'TOKEN_EXPIRED',
        reason: 'Tiền điều kiện SC5 KHÔNG đạt: backend trả error.code=$precheckCode thay vì '
            'TOKEN_EXPIRED. Kiểm tra 06-01 Task 2 (GlobalExceptionHandler.handleAuthentication '
            'phải đọc JwtAuthFilter.ATTR_TOKEN_ERROR) đã được thực thi đúng chưa trước khi tiếp tục.');

    // 4. Bắn 3 request song song KHÔNG await tuần tự — mô phỏng nhiều màn hình cùng gọi lúc thẻ hết hạn.
    final results = await Future.wait([
      apiClient.getList('/wallets'),
      apiClient.getList('/categories'),
      apiClient.getPaged('/transactions', (json) => json),
    ]);

    // 5. Cả 3 đều phải thành công sau khi AuthInterceptor tự làm mới thẻ ngầm.
    expect(results[0], isNotNull);
    expect(results[1], isNotNull);
    expect(results[2], isNotNull);

    // 6. Phiên KHÔNG bị thu hồi oan — gọi thêm 1 request nữa vẫn phải thành công.
    final me = await apiClient.get('/auth/me');
    expect(me['email'], 'seed.user@datn.local');

    await apiClient.clearSession();
  });
}
